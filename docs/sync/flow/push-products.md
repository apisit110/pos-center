this api use for push products from pos client (cashier) to pos center, both create and edit (upsert by product `uid`). Each product is processed one by one. All products of one request get one new `product_version`, so the other pos clients of the store pull the changes with [pull products](./pull-products.md).

**Method**: POST

**Path**: /api/v1/sync/push/products

**Service**: pos-sync-service

request headers:

| key              | value              | required | description                                         |
| ---------------- | ------------------ | -------- | --------------------------------------------------- |
| Content-Type     | `application/json` | true     |                                                     |
| Authorization    | `Bearer <access_token>` | true | access token, see [authentication](./authentication.md) |
| x-correlation-id | string             | false    | correlation id for log, generate uuid if not provided |

request path:

none

request query:

none

request body:

| key                  | type   | required | description                                                  |
| -------------------- | ------ | -------- | ------------------------------------------------------------ |
| mid                  | string | false    | deprecated, merchant `partner_id` (taken from the token)     |
| sid                  | string | false    | deprecated, store `sid` (taken from the token)               |
| products             | array  | true     | list of product to push, min 1 item                          |
| products[].id        | string | true     | product `uid` (generated by pos client), min length 1        |
| products[].barcode   | string | true     | barcode, also saved as `sku`, min length 1                   |
| products[].name      | string | true     | product name, saved as both `name_en` and `name_th`, min length 1 |
| products[].basePrice | number | true     | base price, also saved as store price, >= 0                  |
| products[].imageUrl  | string | false    | image url, nullable                                          |
| products[].unitName  | string | false    | unit name, nullable                                          |
| products[].brand     | string | false    | brand name (`name_en` or `name_th`), nullable                |

example request body:

```json
{
  "products": [
    {
      "id": "PRD-0001",
      "barcode": "8850000000001",
      "name": "Water 600ml",
      "basePrice": 10,
      "imageUrl": null,
      "unitName": "bottle",
      "brand": null
    }
  ]
}
```

response body:

| key               | type   | description                                                 |
| ----------------- | ------ | ----------------------------------------------------------- |
| message           | string | `Products received successfully`                            |
| results           | array  | result of each product, same order as request               |
| results[].id      | string | product `uid` from request                                  |
| results[].status  | string | `synced` (new in the store), `already_synced` (already in the store, updated), `error` |
| results[].error   | string | error message, only when `status` is `error`                |

example response body:

```json
{
  "message": "Products received successfully",
  "results": [
    {
      "id": "PRD-0001",
      "status": "synced"
    }
  ]
}
```

error response:

| http status | body                                                                 | description               |
| ----------- | -------------------------------------------------------------------- | ------------------------- |
| 400         | `{ "message": "Validation failed", "errors": [{ "path": [], "message": "string" }], "request_id": "string" }` | request body is invalid |
| 401         | `{ "message": "Invalid token", "request_id": "string" }` / `{ "message": "Token expired", ... }` | token is missing, invalid or expired, see [authentication](./authentication.md) |
| 403         | `{ "message": "Request does not match the token", "request_id": "string" }` | `mid` / `sid` is not the one of the token |
| 500         | `{ "message": "Internal server error", "request_id": "string" }`     | unexpected error          |

Logic:

- Verify access token, see [authentication](./authentication.md) (401 `Invalid token` / `Token expired`)
- DTO Request
- Validate request body with zod schema
  - mid, sid (deprecated, taken from the token)
    - type: string
    - min: 1
    - required: false
  - products
    - type: array
    - min: 1
    - required: true
    - id, barcode, name
      - type: string
      - min: 1
      - required: true
    - basePrice
      - type: number
      - nonnegative: true
      - required: true
    - imageUrl, unitName, brand
      - type: string
      - nullable: true
      - required: false
  - If validation fails, response http status 400 `Validation failed`
- Check scope of the body
  - only when sent: `mid` = `req.syncAuth.partnerId` and `sid` = `req.syncAuth.sid`, if not, response http status 403 `Request does not match the token`
- Use `partnerId` = `req.syncAuth.partnerId` and `sid` = `req.syncAuth.sid`
- Find merchant by `partner_id` = `partnerId`
  - if not found, every product gets result `error` (`Merchant <partnerId> not found`)
- Find store by `sid` = `sid` AND `merchant_id` = merchant id
  - if not found, every product gets result `error` (`Store <sid> not found`)
- Get next sync version: increase `running_numbers` type `product_version` by 1 (create with 1 if not exists), one version for the whole request
- For each product in `products` (process one by one, error of one product does not stop other products)
  - Find brand by `name_en` = `brand` OR `name_th` = `brand`
    - if `brand` is not provided or not found, `brand_id` = null
  - Find product by `uid` = `id`
    - if found (edit), update `product` (name_en, name_th = `name`, sku, barcode = `barcode`, base_price = `basePrice`, image_url, unit_name, brand_id, updated_at = now)
    - if not found (create), insert `product` (uid = `id`, merchant_id, name_en, name_th = `name`, sku, barcode = `barcode`, base_price = `basePrice`, image_url, unit_name, brand_id)
  - Find `map_store_product` by `product_id` AND `store_id`
    - if found, update `map_store_product` (price = `basePrice`, sync_version, updated_at = now) and push result `already_synced`
    - if not found, insert `map_store_product` (store_id, product_id, price = `basePrice`, stock = 0, sync_version) and push result `synced`
  - if any error, log error and push result `error` with `error` message
- DTO Response
- response http status 200 with `message` and `results`
