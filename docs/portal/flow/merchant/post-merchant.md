this api use for create a new merchant together with its cashier staff, stores (with registered and contract address) and terminals in one request (used in create merchant page). Only Product Owner can create a merchant. The merchant uid, partner id (partner_id), staff username, store id (sid) and terminal id (tid) are generated by the system.

**Method**: POST

**Path**: /api/v1/merchants

**Permission**: `merchants:create`

request headers:

| key           | value            | required | description                                                                |
| ------------- | ---------------- | -------- | -------------------------------------------------------------------------- |
| Authorization | `Bearer <token>` | true     | access token from [login](../auth/post-login.md) (or cookie `token`)        |
| Content-Type  | `application/json` | true   | request body format                                                        |

request path:

none

request query:

none

request body:

| key                                       | type   | required | description                                                              |
| ----------------------------------------- | ------ | -------- | ------------------------------------------------------------------------ |
| name_en                                   | string | true     | merchant name (English), trimmed, min length 1, max length 255           |
| name_th                                   | string | true     | merchant name (Thai), trimmed, min length 1, max length 255              |
| cashier_staff                             | array  | true     | list of cashier staff of the merchant (can be empty)                     |
| cashier_staff[].full_name                 | string | true     | staff name, min length 1, max length 255                                 |
| cashier_staff[].pin                       | string | true     | staff pin, must pass the PIN policy of [pin-repository](../../repositories/pin-repository.md) (6 digits, not weak), stored as bcrypt hash in `pin` |
| cashier_staff[].role                      | string | true     | single role per staff, name of a `cashier_role` (e.g. `manager`, `cashier`) |
| stores                                    | array  | false    | list of store, default `[]`                                              |
| stores[].name_en                          | string | true     | store name (English), min length 1, max length 255                       |
| stores[].name_th                          | string | true     | store name (Thai), min length 1, max length 255                          |
| stores[].registered_address               | object | true     | address of type `REGISTERED` (see address object below)                  |
| stores[].contract_address                 | object | true     | address of type `CONTRACT` (see address object below)                    |
| stores[].terminals                        | array  | false    | list of terminal of the store, default `[]`                              |
| stores[].terminals[].name_en              | string | true     | terminal name (English), min length 1, max length 255                    |
| stores[].terminals[].name_th              | string | true     | terminal name (Thai), min length 1, max length 255                       |

address object (`registered_address` and `contract_address` use the same fields):

| key               | type   | required | description                                                                |
| ----------------- | ------ | -------- | -------------------------------------------------------------------------- |
| address_1         | string | false    | address detail, max length 255                                             |
| province_code     | string | true     | `master_provinces.code` (master data)                                             |
| district_code     | string | true     | `master_districts.code`, must belong to `province_code`                           |
| sub_district_code | string | true     | `master_sub_districts.code`, must belong to `district_code`                       |
| postal_code       | string | true     | `master_postal_code.code`, must belong to `sub_district_code`                     |
| latitude          | number | false    | -90 to 90 (coerce from string), must be sent together with `longitude`     |
| longitude         | number | false    | -180 to 180 (coerce from string), must be sent together with `latitude`    |

Logic:

- Verify access token
  - if fail throw [ServiceError.ErrTokenInvalide](../../../apiresponse/ServiceError.ts)
- Check access token expire
  - throw [ServiceError.ErrTokenExpire](../../../apiresponse/ServiceError.ts)
- Validate Permission `merchants:create` follow [uam](../../uam.md)
  - throw [ServiceError.ErrPermissionDenied](../../../apiresponse/ServiceError.ts)
- DTO Request
- Validate request body with zod schema
  - name_en, name_th
    - type: string
    - trim: true
    - min: 1
    - max: 255
    - required: true
  - cashier_staff
    - type: array of object (full_name: string min 1 max 255, pin: string, role: string min 1)
    - required: true
  - stores
    - type: array of object (name_en: string min 1 max 255, name_th: string min 1 max 255, registered_address: address, contract_address: address, terminals: array of object (name_en: string min 1 max 255, name_th: string min 1 max 255), default [])
    - required: false
    - default: []
  - address
    - type: object (address_1: string max 255 optional, province_code: string min 1, district_code: string min 1, sub_district_code: string min 1, postal_code: string min 1, latitude: number -90..90 optional, longitude: number -180..180 optional)
    - `latitude` and `longitude` must be both present or both absent
  - If validation fails, throw [ValidationError.ErrInvalidRequest](../../../apiresponse/ValidationError.ts)
- Validate the `pin` of every staff with `validatePinPolicy` of [pin-repository](../../repositories/pin-repository.md)
  - if fail throw [ValidationError.ErrInvalidRequest](../../../apiresponse/ValidationError.ts), `details` = `cashier_staff.<index>.pin: <message>`
- Validate `role` of every staff exists in `cashier_role.name` (load roles once)
  - if not found throw [ValidationError.ErrInvalidRequest](../../../apiresponse/ValidationError.ts), `details` = `cashier_staff.<index>.role: not found`
- Resolve master data of every address (`registered_address` and `contract_address` of every store) from `master_provinces`, `master_districts`, `master_sub_districts` and `master_postal_code` by code
  - the chain must match (district in province, sub district in district, postal code in sub district)
  - if not found or not match throw [ValidationError.ErrInvalidRequest](../../../apiresponse/ValidationError.ts), `details` = `stores.<index>.<registered_address|contract_address>.<field>: <message>`
- Generate merchant `uid` (uuid v4)
- Generate merchant `partner_id` from the running number (unique)
  - if `partner_id` already exists, generate a new one and retry
- Generate every staff `username`, store `sid` and terminal `tid` below first (running numbers are not rolled back, gaps are allowed), then save everything below in one database transaction, if any insert fails nothing is saved
- Create merchant in database (uid, partner_id, name_en, name_th)
- Create each staff of `cashier_staff`
  - `uid` = uuid v4
  - `username` = generated from the running number of the merchant `partner_id`
  - `status` = `ACTIVE`
  - `sync_status` = `PENDING`, `sync_id` = null
  - save `cashier_staff` (merchant_id, uid, username, full_name, status, sync_status)
  - save `pin` (uuid v4, app_id of cashier, username, `pin_hash` = bcrypt hash (10 rounds) of `pin`)
  - save `cashier_staff_role` (staff_id, role_id)
- Create each store of `stores`
  - `uid` = uuid v4
  - `sid` = generated from the running number of the merchant `partner_id`
  - save store (merchant_id, uid, sid, name_en, name_th)
  - save `address` of `registered_address` and `contract_address` (province_id, district_id, sub_district_id, postal_code_id, address_1, latitude, longitude)
  - save `map_store_address` (store_id, address_id, type = `REGISTERED` / `CONTRACT`)
  - create each terminal of `terminals` of the store
    - `uid` = uuid v4
    - `tid` = generated from the running number of the store `sid`
    - save terminal (uid, tid, name_en, name_th)
    - save `map_store_terminal` (store_id, terminal_id)
- DTO Response
- wrap the response with [Ok](../../../apiresponse/Ok.ts) (`res_code` `0000`), the response items below are `data`
- response `201 Created` with merchant follow these items (uid, partner_id, name_en, name_th, cashier_staff, stores)
