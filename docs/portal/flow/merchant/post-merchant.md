this api use for create a new merchant together with its staff, stores and terminals in one request (used in create merchant page). Only Product Owner can create a merchant. The merchant uid, merchant id (mid), staff username, store id (sid) and terminal id (tid) are generated by the system.

**Method**: POST

**Path**: /api/v1/merchants

**Permission**: `merchants:create`

request headers:

| key           | value            | required | description                                                                |
| ------------- | ---------------- | -------- | -------------------------------------------------------------------------- |
| Authorization | `Bearer <token>` | true     | access token from [login](../auth/post-login.md) (or cookie `token`)        |
| Content-Type  | `application/json` | true   | request body format                                                        |

request path:

none

request query:

none

request body:

| key                              | type   | required | description                                                              |
| -------------------------------- | ------ | -------- | ------------------------------------------------------------------------ |
| name                             | string | true     | merchant name, trimmed, min length 1                                     |
| staff_members                    | array  | true     | list of staff of the merchant (can be empty)                             |
| staff_members[].full_name        | string | true     | staff name, min length 1                                                 |
| staff_members[].pin              | string | true     | staff pin, min length 1 (stored as bcrypt hash)                          |
| staff_members[].role             | string | true     | `manager` or `cashier`                                                   |
| stores                           | array  | false    | list of store, default `[]`                                              |
| stores[].name                    | string | true     | store name, min length 1                                                 |
| stores[].address                 | string | true     | store address                                                            |
| stores[].latitude                | number | true     | latitude (coerce from string)                                            |
| stores[].longitude               | number | true     | longitude (coerce from string)                                           |
| stores[].terminals               | array  | false    | list of terminal of the store, default `[]`                              |
| stores[].terminals[].name        | string | true     | terminal name, min length 1                                              |

example request body:

```json
{
  "name": "string",
  "staff_members": [
    {
      "full_name": "string",
      "pin": "string",
      "role": "manager"
    }
  ],
  "stores": [
    {
      "name": "string",
      "address": "string",
      "latitude": 13.7563,
      "longitude": 100.5018,
      "terminals": [{ "name": "string" }]
    }
  ]
}
```

response body (fields below are the value of `data`, wrapped in [Ok](../../../apiresponse/middleware.md#ok)):

| key  | type   | description                               |
| ---- | ------ | ----------------------------------------- |
| uid  | string | merchant uid (generated)                  |
| mid  | string | merchant id (generated, unique)           |
| name | string | merchant name                             |

example response body:

```json
{
  "res_code": "0000",
  "res_desc": "",
  "data": {
    "uid": "string",
    "mid": "string",
    "name": "string"
  }
}
```

Logic:

- Verify access token
  - if fail throw [ServiceError.ErrTokenInvalide](../../../apiresponse/ServiceError.ts)
- Check access token expire
  - throw [ServiceError.ErrTokenExpire](../../../apiresponse/ServiceError.ts)
- Validate Permission `merchants:create` follow [uam](../../uam.md)
  - throw [ServiceError.ErrPermissionDenied](../../../apiresponse/ServiceError.ts)
- DTO Request
- Validate request body with zod schema
  - name
    - type: string
    - trim: true
    - min: 1
    - required: true
  - staff_members
    - type: array of object (full_name: string min 1, pin: string min 1, role: enum `manager` | `cashier`)
    - required: true
  - stores
    - type: array of object (name: string min 1, address: string, latitude: number, longitude: number, terminals: array of object (name: string min 1), default [])
    - required: false
    - default: []
  - If validation fails, throw [ValidationError.ErrInvalidRequest](../../../apiresponse/ValidationError.ts)
- Generate merchant `uid` (uuid v4)
- Generate merchant `mid` from the running number (unique)
  - if `mid` already exists, generate a new one and retry
- Create merchant in database (uid, mid, name)
- Create each staff of `staff_members`
  - `uid` = uuid v4
  - `username` = generated from the running number of the merchant `mid`
  - `pin` = bcrypt hash (10 rounds) of `pin`
  - `status` = `ACTIVE`
  - save staff with the role
- Create each store of `stores`
  - `uid` = uuid v4
  - `sid` = generated from the running number of the merchant `mid`
  - save store (name, address, latitude, longitude) of the merchant
  - create each terminal of `terminals` of the store
    - `uid` = uuid v4
    - `tid` = generated from the running number of the store `sid`
    - save terminal (name) of the store
- DTO Response
- wrap the response with [Ok](../../../apiresponse/Ok.ts) (`res_code` `0000`), the response items below are `data`
- response `201 Created` with merchant follow these items (uid, mid, name)
